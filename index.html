手动搭建步骤

1
新建快捷指令
  • 打开 快捷指令 App → 右上角 + 新建
  • 点击顶部名称，改名为 「夺回注意力」
2
添加「要求输入」
  • 搜索并添加动作 要求输入（Ask for Input）
  • 类型选 文本
  • 提示语填：想搜什么？
这一步的作用
弹出一个输入框，让你直接打字输入要搜索的关键词，不用先打开App。
3
添加「URL编码」
  • 搜索并添加动作 URL编码（URL Encode）
  • 输入选择 要求输入的结果
为什么需要这步
中文关键词需要编码成 URL 格式（比如"减脂"变成 %E5%87%8F%E8%84%82），否则链接会打不开。
4
添加「从列表中选择」
  • 搜索并添加动作 从列表中选择（Choose from List）
  • 选项依次填入：小红书、B站、知乎、抖音、微博、Google、Bing
  • 提示语填：在哪个平台搜？
5
添加「词典」+「获取词典值」

这一步是核心——用词典把平台名映射到搜索URL模板。

  • 搜索添加 词典（Dictionary），填入下面的键值对
  • 再添加 获取词典值（Get Dictionary Value）
  • 键设为上一步选择的平台，输入设为词典

词典内容（直接复制对应的URL，把 {keyword} 作为占位符）：

键（平台）值（URL模板）
小红书https://www.xiaohongshu.com/search_result?keyword={keyword}
B站https://search.bilibili.com/all?keyword={keyword}
知乎https://www.zhihu.com/search?q={keyword}&type=content
抖音https://www.douyin.com/search/{keyword}
微博https://m.weibo.cn/search?containerid=1034&type=uid&q={keyword}
Googlehttps://www.google.com/search?q={keyword}
Binghttps://www.bing.com/search?q={keyword}
6
添加「替换文本」
  • 搜索添加 替换文本（Replace Text）
  • 查找文本填：{keyword}
  • 替换为填：URL编码的结果（第3步的输出变量）
  • 文本填：获取词典值的结果（第5步的输出）
这步在干嘛
把URL模板里的 {keyword} 占位符，替换成你实际输入的、编码后的关键词，拼出最终链接。
7
添加「打开URL」
  • 搜索添加 打开URL（Open URL）
  • URL填：替换文本的结果（第6步的输出）

完成！整个动作链如下：

要求输入 → URL编码 → 从列表中选择 → 词典 → 获取词典值 → 替换文本 → 打开URL

极简版（只要小红书）

如果你只在小红书搜东西，不需要多平台选择，可以省掉"选择列表"和"词典"两步：

  • 要求输入 → 提示语"想搜什么？"，类型"文本"
  • URL编码 → 输入选"要求输入的结果"
  • URL → 填入下面的链接（注意把编码结果接在 keyword= 后面）
  • 打开URL → URL选上一步的结果
https://www.xiaohongshu.com/search_result?keyword=［这里拖入URL编码的输出变量］ 点击复制

📱 添加到主屏幕（关键一步）

创建好快捷指令后，把它放到主屏幕，就能像App一样点开就用：

  1. 在快捷指令详情页，点击右下角的 i 信息按钮
  2. 点击 添加到主屏幕
  3. （可选）点击图标改成灰色，降低视觉吸引力
  4. 点击右上角 添加 完成
💡 视频作者的核心技巧
把图标设成灰色，是为了降低你随手点开刷推荐的冲动。颜色越灰暗，越不容易触发"随手打开"的肌肉记忆。

用深度链接直接打开App

上面的方案打开的是网页版。如果你装了对应App，可以用 App深度链接 直接跳到App内的搜索页：

平台App深度链接
小红书xhsdiscover://search_result?keyword={keyword}
B站bilibili://search?keyword={keyword}
知乎zhihu://search?q={keyword}
抖音snssdk1128://search?keyword={keyword}
微博sinaweibo://search?q={keyword}

把词典里的网页URL换成上面的深度链接即可。推荐用深度链接，体验更流畅。
